Política de privacidad

Ámbito: integración personal y de uso exclusivo de su titular entre Google Health, Google Apps Script y una hoja privada de Google Sheets.

Datos a los que accede

La integración accede únicamente a los datos necesarios para obtener el recuento diario de pasos mediante el permiso de solo lectura googlehealth.activity_and_fitness.readonly. No solicita permisos de escritura ni acceso a ubicación, sueño, frecuencia cardiaca, peso, nutrición u otras categorías de salud.

Finalidad

Los pasos se utilizan exclusivamente para mantener un registro personal de actividad física, analizar la continuidad diaria y relacionarla con el seguimiento del entrenamiento.

Almacenamiento

Los totales diarios se guardan en una hoja privada de Google Sheets propiedad del titular. Los datos de autorización se conservan en los almacenes privados de Google Apps Script necesarios para mantener la sincronización. Esta web pública no recibe, procesa ni almacena datos de Google Health.

Compartición y venta

Los datos no se venden, no se utilizan para publicidad y no se comparten con terceros. No se transfieren fuera de los servicios de Google utilizados por el propio titular para esta integración.

Conservación y eliminación

Los registros permanecen en la hoja privada hasta que el titular los elimina. El acceso puede revocarse desde la configuración de seguridad de la Cuenta de Google. También pueden eliminarse el token de autorización, el proyecto de Apps Script y los registros de la hoja.

Seguridad

El acceso se protege mediante la cuenta de Google del titular, OAuth 2.0 y los controles de acceso de Google Sheets y Apps Script. No se publican credenciales, tokens ni datos de actividad en el repositorio o en esta web.

Uso limitado de datos de Google

El uso de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de Uso Limitado.

Cambios

Esta política se actualizará si cambia la finalidad, el tipo de datos consultado o la forma de almacenamiento.
